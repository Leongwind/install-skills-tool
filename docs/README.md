# Project records

This directory preserves the decisions needed to continue Skill Installer across
machines and Codex sessions.

- `development-history.md`: chronological releases, fixes, and commits.
- `conversations/`: structured summaries of user decisions and reported issues.
- `plans/`: immutable plan snapshots for each major development phase, including macOS 0.4.0
  and 0.4.1.
- `handoffs/`: current-machine testing instructions and result templates.

Start from the repository root `PROJECT_CONTEXT.md`.
