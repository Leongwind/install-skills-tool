# 隐私与诊断边界

Skill Installer 是本地工具。默认不会上传遥测、Skill 内容或本地路径，也不需要云端账号。公开 GitHub 来源只在用户点击检查时访问公开 URL，下载内容先进入本地临时缓存。

诊断导出包含 IDE 检测结果、版本、库存数量、规范状态、管理状态、操作结果摘要和备份元数据。用户主目录会替换为 `~`，不会包含 `SKILL.md`、附属文件内容或文件树原文。导出前 UI 会提示包含的信息，用户必须主动复制或保存。

日志用于本地故障排查，路径会脱敏。若向 issue 提供诊断，请先删除用户名、项目路径、私有 URL、令牌和 Skill 描述中的敏感信息。安全问题请参考 [SECURITY.md](../SECURITY.md)。
