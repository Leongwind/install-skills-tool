# Structured conversation record

This is a decision summary, not a verbatim transcript.

## Product direction

The product began as a one-click local Skill installer that scans installed AI IDEs,
lets the user choose multiple targets, and installs the same Skill safely. macOS and
Windows are separate applications and installation packages. Stable concepts may be
copied, but there is no shared cross-platform source package.

## macOS decisions

- Supported Agents: Codex, Claude Code, Kiro, Cursor, Windsurf, TRAE International,
  and TRAE China.
- TRAE uses native Agent Skills rather than converted rules.
- Sources expanded from one local or GitHub Skill to local directory, ZIP, and public
  GitHub sources that may contain multiple Skills.
- The assignment UI became a per-Skill, per-IDE matrix.
- New project-scoped installation was removed. New installations are global only.
- Inventory groups Skills by IDE and distinguishes managed, adopted, external,
  modified, unsafe, and passive entries.
- External Skills require explicit adoption before managed uninstall.
- Codex inventory reads both `~/.agents/skills` and legacy `~/.codex/skills`.

## Reported macOS issues and outcomes

- GitHub archives containing symlinks were incorrectly rejected. Validation was
  narrowed to selected Skill content.
- The default window was uncomfortable at compact sizes. Responsive layout and Codex
  detection were corrected.
- The source search field inherited metric-card styling. Dedicated metric selectors
  repaired its position.
- Earlier Codex Skills were absent from inventory. Legacy Codex roots were added.

## Windows decisions

- Windows lives in top-level `windows/` and starts at version `0.1.0`.
- The release target is Windows 10/11 x64 with an NSIS installer.
- The current Mac will not install VMware for this development phase.
- Fixtures verify assignment planning and synthetic file behavior, not real IDE
  visibility.
- GitHub Actions verifies the real Windows x64 build and synthetic integration flow.
- The user will perform final validation on a real Windows 11 x64 machine after the
  implementation and CI phases are complete.
- Real multi-IDE validation uses Cursor and Kiro.
- Every completed Windows milestone must be committed and pushed to `main`.
- Project history, plan snapshots, and a Windows test handoff must live in the repo so
  Windows Codex can continue without this chat session.
